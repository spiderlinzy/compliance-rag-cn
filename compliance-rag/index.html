Compliance RAG

A minimal, verifiable financial-compliance question answerer: every fact is traceable to a source, it refuses when nothing is retrieved, and confidence follows the FTH trust level of the material — not the model's subjective score.

01

What it is

A single-turn command-line tool (with a local web UI) that answers financial-compliance questions only from four designated documents. The point is not polished answers — it is never fabricating, staying verifiable, and remaining auditable. It is the companion practice project that runs the book's most abstract trust-layering and RAG-security mechanisms in the smallest possible code.

The same evidence chain shown conceptually in the Assessor and at enterprise scale in the Case File is real, runnable code here — no mock interface.

02

Core mechanisms

Two refusal lines

A zero-cost hard block at retrieval when no lexical match exists, plus a model semantic answerability check when wording is related but no answer is present.

Mandatory citation anchoring

Output is structured JSON; every statement carries a citation id and no unsourced statement is allowed.

Independent citation verifier

A separate call first checks structure (does the citation id exist), then semantics (does the source support the claim), balancing the generator's power.

Controlled glossary

Definitional, uncontroversial classifications are written as an auditable whitelist rather than relying on the model's implicit common sense.

FTH graded confidence

Confidence is labelled by source tier — highest for shared conclusions, lowest for differing ones — never exceeding the material's trust level.

Local BM25 retrieval

Runs without an embedding endpoint; the retrieval module can be swapped for vector search without changing any other stage.
